## Deploy

If this is replacing the files in your existing `ArthurBates/portfolio` repo:

1. Open the repository on GitHub.
2. Delete or replace the old `index.html`, `style.css`, and `script.js`.
3. Upload the three new files from this ZIP.
4. Commit the changes.
5. If GitHub Pages is already enabled, the updated site should deploy automatically.

If Pages is not enabled:
- Settings → Pages
- Source: Deploy from a branch
- Branch: `main`
- Folder: `/ (root)`
